# Piratheep Rajaratnam — Portfolio

Personal portfolio built with **Next.js** and **Tailwind CSS**, deployed on Vercel at https://piratheep.vercel.app

## Edit content
All text, projects, experience and skills live in `lib/data.js`. Images are in `public/` (`public/projects/` for project screenshots).

To add a "Download CV" button, put a PDF at `public/cv.pdf` and set `cvUrl: "/cv.pdf"` in `lib/data.js`.

## Run locally
```bash
npm install
npm run dev
```
